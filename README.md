# SKD — Sunkiran Dimex agency site

Static website for **Sunkiran Dimex**, a Meta Ads & Instagram marketing agency.

## What it does
- Multi-page marketing site: home, services, workshop, about, contact, plus legal
  pages (privacy, terms, refund).
- Plain HTML/CSS/JS — no build step.

## How to operate
- Open `index.html` in a browser, or `npx serve .`.
- Deploy to any static host (Pages / Netlify / Hostinger).
